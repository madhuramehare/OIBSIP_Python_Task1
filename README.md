# BMI_CALCULATOR

 Objective
To develop a user-friendly Python application that calculates **Body Mass Index (BMI)** from a user's weight and height and displays the corresponding BMI category.

 Steps Performed
1. Created a GUI using Tkinter.
2. Added input fields for user name, weight, and height.
3. Implemented the BMI calculation formula.
4. Classified BMI into different categories.
5. Stored user BMI records using SQLite.
6. Added BMI history and trend visualization using Matplotlib.
7. Added input validation and error handling.
8. Tested the application with different user inputs.

Tools Used
- Python
- Tkinter
- SQLite3
- Matplotlib
- VS Code

 Outcome
Successfully developed a **BMI Calculator** that calculates and categorizes BMI, stores user records, displays BMI history, and visualizes BMI trends through a graph.
